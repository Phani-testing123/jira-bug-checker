# Jira Bug Quality Checker

Internal QA tool to identify Jira bugs missing:
- Environment
- Priority
- Severity

Also supports:
- Slack Dry-Run (preview)
- Slack Send (All)
- Slack Re-Send (Selected)
- Excel export

---

## Tech Stack
- Python
- Flask
- Jira REST API
- Slack API

---

## How to Run (Local)

```bash
python3 app.py
